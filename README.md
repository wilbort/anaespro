# Optimización de Rutas de Delivery

App interactiva que compara tres algoritmos para resolver el Problema del Viajero (TSP):
- Fuerza Bruta — O(n!)
- Algoritmo Voraz — O(n²)
- Programación Dinámica (Held-Karp) — O(n² × 2ⁿ)

## Cómo ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy en Streamlit Cloud

1. Sube esta carpeta a un repositorio público en GitHub
2. Entra a https://share.streamlit.io
3. Conecta tu cuenta de GitHub
4. Selecciona el repositorio y el archivo `app.py`
5. Click en Deploy — en 2 minutos tienes el enlace
